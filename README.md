
# Electrical Load — лабораторная работа №5

Фронтенд-приложение для просмотра электроприборов и их характеристик.

Приложение разработано на React и TypeScript с использованием Vite, React-Bootstrap и React Router.

В лабораторной работе №5 реализован интерфейс гостя с двумя доступными страницами: «Лента» и «Каталог (плитка)». Пункты «Добавить» и «Войти» присутствуют в нижнем меню, но пока недоступны.

Данные электроприборов берутся из локального массива `ELECTRICITY_CONSUMERS_MOCK`, расположенного в `src/data/mock.ts`. Для отображения карточек подключение к бэкенду не используется.

## Страницы приложения

### 1. Лента

**Адрес:** `/`

Страница предназначена для последовательного просмотра электроприборов. На экране отображается один электроприбор за раз.

| Элемент | Тип | Описание |
|---|---|---|
| Видео | Видео | Вертикальное видео электроприбора. Воспроизводится автоматически, без звука и с повторением. При отсутствии видео используется `/media/default.mp4`. |
| Название | Текст | Название отображаемого электроприбора. |
| Описание | Текст | Краткое описание электроприбора. |
| Больше / Меньше | Кнопка | Разворачивает и сворачивает описание прибора. |
| Лайки | Текст и иконка | Отображение количества лайков электроприбора. Для гостя изменение лайков недоступно. |
| Мощность | Текст | Электрическая мощность прибора в кВт. |
| Сила тока | Текст | Сила тока электроприбора в амперах (А). |
| Стрелка вниз | Кнопка | Переключает ленту на следующий электроприбор. После последнего прибора снова отображается первый. |

Для отображения информации используются mock-данные. Переключение электроприборов и раскрытие описания реализованы с помощью хука `useState`.

### 2. Каталог (плитка)

**Адрес:** `/catalog`

Страница предназначена для просмотра электроприборов в виде карточек, расположенных в две колонки. Предусмотрена фильтрация по диапазону электрической мощности.

| Элемент | Тип | Описание |
|---|---|---|
| Минимальная мощность | Текст | Отображает выбранную нижнюю границу диапазона мощности в кВт. |
| Максимальная мощность | Текст | Отображает выбранную верхнюю границу диапазона мощности в кВт. |
| Двойной слайдер | Поле с двумя ползунками | Позволяет выбрать минимальную и максимальную мощность от 0 до 5 кВт с шагом 0,1 кВт. |
| Найти | Кнопка | Применяет выбранный диапазон мощности к mock-коллекции. |
| Изображение | Изображение | Фотография электроприбора. При отсутствии изображения используется `/media/default.jpg`. |
| Название | Текст | Название электроприбора в карточке. |
| Мощность | Текст | Значение электрической мощности прибора в кВт. |
| Лайки | Текст и иконка | Количество лайков электроприбора. |
| Подробнее | Кнопка | Выполняет переход на страницу ленты электроприборов. |
| Сообщение об отсутствии результатов | Текст | Появляется, если ни один прибор не соответствует выбранному диапазону мощности. |

Значения ползунков хранятся с помощью хука `useState`. После нажатия кнопки «найти» применяется фильтрация массива электроприборов методом `filter()`.

Данные карточек получаются только из mock-объектов. Запросы к серверу для фильтрации не выполняются.

### 3. Добавление электроприбора

**Статус:** недоступно в ЛР5.

Страница предназначена для создания и публикации электроприборов авторизованным пользователем. В текущей лабораторной работе пункт «Добавить» отображается в нижней панели, но не открывает страницу.

Ниже приведено описание элементов, предусмотренных для реализации в следующих лабораторных работах.

| Элемент | Тип | Описание |
|---|---|---|
| Видео | Поле выбора файла | Выбор короткого видео электроприбора. |
| Фото | Поле выбора файла | Выбор изображения электроприбора. |
| Название | Текстовое поле | Ввод названия электрического прибора. |
| Далее | Кнопка | Создание черновика с названием, изображением и видео. |
| Описание | Многострочное текстовое поле | Ввод краткого описания электроприбора. |
| Мощность, кВт | Числовое поле | Ввод электрической мощности прибора. |
| Сила тока | Вычисляемое значение | Рассчитывается автоматически по мощности при напряжении 220 В. |
| Опубликовать | Кнопка | Сохранение заполненных параметров и публикация электроприбора. |

В дальнейшем создание и публикация записей будут выполняться через REST API. Изображения и видео предусмотрено хранить в MinIO, а сведения об электроприборах — в PostgreSQL.

В ЛР5 данные функции не реализуются.

### 4. Вход

**Статус:** недоступно в ЛР5.

Страница предназначена для аутентификации и регистрации пользователей. В текущей лабораторной работе пункт «Войти» отображается в нижнем меню, но не открывает страницу.

Планируемые элементы страницы:

| Элемент | Тип | Описание |
|---|---|---|
| Логин | Текстовое поле | Ввод логина пользователя. |
| Пароль | Поле пароля | Ввод пароля со скрытием вводимых символов. |
| Войти | Кнопка | Проверка логина и пароля, получение JWT-токена и переход в интерфейс авторизованного пользователя. |
| Зарегистрироваться | Кнопка | Регистрация нового пользователя с указанными логином и паролем. |

В следующих лабораторных работах аутентификация и регистрация будут выполняться через REST API.

В ЛР5 формы входа и регистрации не реализуются.

## Нижняя навигация

В нижней части приложения расположена навигационная панель из четырёх пунктов.

| Пункт | Статус | Описание |
|---|---|---|
| Лента | Доступен | Переход на страницу `/`. |
| Добавить | Недоступен | Раздел создания электроприбора, запланированный для следующих лабораторных работ. |
| Каталог | Доступен | Переход на страницу `/catalog`. |
| Войти | Недоступен | Раздел аутентификации пользователя, запланированный для следующих лабораторных работ. |

Активный пункт навигации выделяется бирюзовым цветом.

Переход между доступными страницами выполняется средствами React Router без полной перезагрузки приложения.

## Используемые технологии

| Технология | Назначение |
|---|---|
| React | Разработка интерфейса на основе компонентов. |
| TypeScript | Типизация данных электроприборов и props компонентов. |
| Vite | Создание проекта, локальный сервер разработки и сборка. |
| React-Bootstrap | Компоненты карточек и кнопок. |
| React Router | Маршрутизация между страницами. |
| CSS | Оформление ленты, каталога и навигационной панели. |

Для хранения состояния используется хук `useState`. В каталоге также используется `useNavigate` для программной навигации.

Массив `ELECTRICITY_CONSUMERS_MOCK` передаётся компонентам `FeedPage` и `CatalogPage` через `props`.

## Запуск приложения

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера разработки:

```bash
npm run dev
```

Приложение доступно по адресу:

`http://localhost:5173/`

Создание производственной сборки:

```bash
npm run build
```
