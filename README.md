
# Electrical Load — лабораторная работа №5

Фронтенд-приложение для просмотра электроприборов и их характеристик.

Приложение разработано на React и TypeScript с использованием Vite, React-Bootstrap и React Router. Интерфейс предназначен для гостя и состоит из двух страниц: ленты и каталога (плитки).

Данные электроприборов берутся из локального массива `ELECTRICITY_CONSUMERS_MOCK`, расположенного в файле `src/data/mock.ts`. Для отображения карточек подключение к бэкенду не используется.

## Страницы приложения

### Лента — /

Страница предназначена для последовательного просмотра электроприборов. На экране отображается один прибор за раз.

- Фоновое видео демонстрирует электроприбор. При отсутствии видео используется локальный файл `/media/default.mp4`.
- В нижней части страницы отображаются название и описание прибора.
- Кнопка «больше» раскрывает описание полностью, «меньше» сворачивает его.
- Справа отображаются количество лайков, мощность в кВт и сила тока в А.
- Количество лайков отображается в информационных целях.
- Кнопка со стрелкой вниз переключает ленту на следующий электроприбор. После последней записи снова отображается первая.

### Каталог (плитка) — /catalog

Страница предназначена для просмотра электроприборов в виде плитки из двух колонок.

- Каждая карточка содержит изображение прибора, название, мощность в кВт и количество лайков.
- При отсутствии изображения используется локальный файл `/media/default.jpg`.
- В карточках предусмотрена кнопка «Подробнее», выполняющая переход к странице ленты.
- Фильтр по мощности содержит два ползунка для выбора минимального и максимального значений от 0 до 5 кВт с шагом 0,1 кВт.
- Кнопка «найти» применяет выбранный диапазон мощности.
- После применения фильтра отображаются только приборы, мощность которых входит в выбранный диапазон.
- Если подходящие приборы отсутствуют, выводится соответствующее сообщение.

## Нижняя навигация

В нижней части приложения расположена панель из четырёх пунктов:

- **Лента** — переход к странице последовательного просмотра электроприборов.
- **Добавить** — недоступно для гостя.
- **Каталог** — переход к странице плитки с фильтрацией.
- **Войти** — недоступно в данной лабораторной работе.

Активный пункт навигационной панели выделяется бирюзовым цветом.

## Используемые технологии

- React — создание интерфейса на основе компонентов.
- TypeScript — типизация данных и свойств компонентов.
- Vite — среда разработки и сборка приложения.
- React-Bootstrap — компоненты интерфейса.
- React Router — маршрутизация между страницами.
- CSS — оформление приложения.

Для хранения состояния компонентов используется хук `useState`. Данные электроприборов передаются компонентам через `props`.

## Запуск приложения

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера:

```bash
npm run dev
```

Приложение доступно по адресу `http://localhost:5173/`.

Создание сборки:

```bash
npm run build
```
